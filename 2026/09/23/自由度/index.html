自由度

一、自由度的基本概念

1.1 自由度的定义

任何一个工件在空间直角坐标系中都有且只有六个自由度，即沿X、Y、Z三个坐标轴方向的移动自由度（分别记为 (\vec{x})、(\vec{y})、(\vec{z})）和绕这三个坐标轴的转动自由度（分别记为 (\hat{x})、(\hat{y})、(\hat{z})）。这六个独立运动决定了工件在空间中的位置和姿态。

1.2 工件定位的实质

工件在夹具中定位，其实质就是根据零件加工要求，设置定位元件来限制那些影响加工精度的自由度，使工件取得正确的位置。定位的目的是使同一批工件在加工时占有一致的正确加工位置。

1.3 自由度与定位、夹紧的区别

定位与夹紧是两个完全不同的概念，必须严格区分。定位是通过定位元件限制工件的自由度，使工件在夹具中占有确定的位置；夹紧是对工件施加外力，使其已确定的位置在加工过程中保持不变。约束自由度的分析不考虑外力影响，工件在外力作用下不能运动是夹紧的任务，而非定位的任务。

二、六点定位原理

2.1 基本原理

对于确定的刚体，如果设置相应的六个约束，分别用于限制该刚体的六个运动自由度，就可以使该自由刚体在空间有一个确定的位置，该方法称为六点定位原理。用合理分布的六个支承点限制工件的六个自由度，使工件在夹具中占据正确的位置，称为六点定位法则。

2.2 典型示例

以长方体工件在铣床上加工不通槽为例，用六个支承点的布置方式加以说明：

  • 主定位面A（底面）：布置三个支承点 a1、a2、a3，限制Z方向的移动自由度以及绕X、Y方向的旋转自由度（共限制3个自由度）；
  • 侧面B：布置两个支承点 a4、a5，限制X方向的移动自由度和绕Z方向的旋转自由度（共限制2个自由度）；
  • 止推面C：布置一个支承点 a6，限制Y方向的移动自由度（限制1个自由度）。

这样，工件的六个自由度全部被限制，实现完全定位。

2.3 支承点与定位元件的区别

需要特别注意的是，“定位点”与“支承点”是两个不同的概念。支承点是安装在夹具上直接与工件接触的具体定位元件，如支承钉、支承板、V形块等；而定位点是一个抽象概念，是指定位方式对自由度的限制。限制一个自由度称为一个定位点，与支承点的多少无关。例如，工件直接以平面定位时，应限制三个自由度，只应有三个定位点，而实际支承点的数量可能远多于三个。

在夹具的实际结构中，支承点通过具体的定位元件来体现，通常采用面或线来代替点：一条直线可以代替两个支承点，一个平面可代替三个支承点。

2.4 定位支承点起作用的条件

定位支承点限制工件自由度的作用，应理解为定位支承点与工件定位基准面始终保持紧贴接触。若二者脱离，则支承点就失去了限制自由度的作用。

三、定位的四种类型

根据工件六个自由度被限制的情况，工件在夹具中的定位可分为以下四种类型：

3.1 完全定位

工件的六个自由度均被夹具定位元件所限制，使工件在夹具中处于完全确定的位置。当工件在X、Y、Z三个坐标方向上均有尺寸或位置精度要求时，一般采用完全定位方式。

3.2 不完全定位

根据工件加工精度要求，不需要限制全部六个自由度的定位，称为不完全定位。虽然没有完全限制工件的六个自由度，但保证加工精度的自由度已全部限制，因此也是合理的定位，在实际夹具定位中普遍存在。

例如，在工件上铣台阶面时，只需保证工序尺寸y、z及与底面、侧面的平行度，只要限制五个自由度就够了，不必限制沿X轴移动的自由度，因为它对工件的加工精度并无影响。

采用完全定位还是不完全定位，主要由该工序的加工要求来决定。对不必限制的自由度，一般不应布置支承点，否则将使夹具结构变得复杂，增加夹具制造成本。

3.3 欠定位

根据工件加工精度要求需要限制的自由度没有得到完全限制的定位，称为欠定位。欠定位的结果将导致工件无法满足工序加工要求，确定工件在夹具中的定位方案时，绝对不允许发生欠定位这样的原则性错误。

但在某些特殊情况下，当工件上没有足够精确的定位面时，用定位元件定位就无法可靠保证工件在某方向的准确位置，此时不能用定位元件限制工件在这些方向的自由度，这些自由度可以采用划线找正的方法加以限制。

3.4 过定位

定位元件的一组限位面重复限制工件的同一个自由度的定位，称为过定位。

过定位可能导致定位干涉或工件装不上定位元件，进而导致工件或定位元件产生变形、定位误差增大，因此在定位设计中应该尽量避免过定位。但另一方面，过定位可以提高工件的局部刚度和工件定位的稳定性，所以在加工刚性差的工件时，过定位又是非常必要的。

在实际应用中，有的过定位是形式上的，称为“假过定位”；有的过定位对加工结果影响不大，却带来了一些益处。过定位的出现应依据是否满足加工要求来进行综合判断。

3.5 四种定位类型的对比

定位类型 限制自由度数 是否合理 典型场景
完全定位 6个 合理 三个方向均有精度要求
不完全定位 1～5个 合理 部分方向无精度要求
欠定位 少于工序要求 不合理（绝对禁止） 应限制的自由度未限制
过定位 存在重复限制 一般避免，特定场合允许 刚性差工件、精密加工

四、常见定位元件与自由度约束的对应关系

4.1 主要定位元件及其约束的自由度

不同的定位元件所能限制的自由度数量和种类各不相同：

  • 支承钉/支承板（平面定位） ：一个平面可限制3个自由度（1个移动，2个转动）；
  • 短圆柱销：限制2个自由度（2个移动）；
  • 长圆柱销：限制4个自由度（2个移动，2个转动）；
  • 短V形块：限制2个自由度（2个移动）；
  • 长V形块：限制4个自由度（2个移动，2个转动）；
  • 圆锥销：限制3个自由度（3个移动）；
  • 小端面：限制1个移动自由度；
  • 大端面：限制3个自由度（1个移动，2个转动）；
  • 圆柱销与工件侧面接触：限制1个自由度。

4.2 组合定位中的自由度判断

在组合定位中，各定位元件在单独定位时限制的自由度可能发生变化。工件需要约束的自由度数和自由度由所选择的定位基准几何特征决定，而定位元件约束工件自由度数和自由度则与具体接触情况有关。例如，同样是圆柱销，当作为短销与孔配合时限制2个自由度，当作为长销与孔配合时限制4个自由度，当与工件侧面接触时仅限制1个自由度。

五、自由度与加工精度的关系

5.1 工序加工要求决定应限制的自由度

工件自由度的合理约束是夹具设计的关键。基于刚体运动学，可以建立描述加工要求和理论约束自由度之间关系的自由度模型。研究结果表明，当被加工面分别为1、2、3个方位有位置要求时，需要限制工件的自由度分别为3、5、6个。

5.2 自由度对加工要求的影响

随着科技水平的进步，机械智能制造工件的自由度会对加工要求和加工效率产生一定影响。针对常见加工表面不同情况下自由度的影响，需要分析工件的自由度与加工要求的关系，为设计定位方案提供依据。

5.3 定位误差与自由度的关系

从零件几何精度的标注模式出发，可以分别建立工件几何精度的标注自由度模型和工件定位自由度模型，基于这两个自由度模型建立工件定位状态判别规则，从而判断工件定位的合理性。

六、自由度分析在夹具设计中的应用

6.1 分析步骤

在夹具设计中，自由度分析的典型步骤如下：

  1. 分析工序加工要求：明确该工序需要保证的尺寸精度和位置精度；
  2. 确定需要限制的自由度：根据加工要求，确定哪些自由度必须限制，哪些可以不必限制；
  3. 选择定位基准和定位元件：根据工件结构特点选择合适的定位基准面，并确定对应的定位元件；
  4. 分析各定位元件限制的自由度：逐一分析每个定位元件实际限制的自由度；
  5. 判断定位是否合理：检查是否存在欠定位或过定位，必要时调整定位方案。

6.2 基于齐次线性方程组的分析方法

针对传统方法难以解决复杂定位问题的不足，研究者提出了基于齐次线性方程组的工件自由度分析技术。该方法根据齐次线性方程组解结构的性质，推导了三个定位方案的合理性判据，并建立了描述加工要求和理论约束自由度之间关系的自由度模型。

6.3 基于定位法线的几何定理方法

传统的六点定位原理只能够感性地判断工件在夹具中的自由度，难以解决一些疑难定位问题，例如对于复杂曲面定位的情况。为此，研究者将工件在夹具定位点处的法线命名为定位法线，根据定位法线的数量及其几何关系推导出一组判断工件自由度的几何定理，并对工件过定位时所对应的法线分布情况给出判断准则，使工件自由度的判断方法更加严谨、简单、直观。

6.4 过定位的解决方案

在夹具设计中，正确处理过定位问题至关重要。当出现过定位时，可以采取以下措施：改变定位元件间的装配关系；改变定位元件的形状尺寸；提高过定位定位元件的精度。在实际应用中，需要根据具体情况综合判断过定位是否可以接受。

七、总结

自由度理论是夹具设计的核心基础。在工装设计和夹具设计中，正确理解和应用自由度知识，需要把握以下几个要点：

  1. 理论基础：工件在空间有6个自由度（3个移动+3个转动），六点定位原理是判断定位方案的基本准则；
  2. 定位类型：完全定位、不完全定位是合理的，欠定位绝对不允许，过定位需根据具体情况综合判断；
  3. 元件对应：不同定位元件限制的自由度数量和种类不同，需根据定位基准的几何特征正确判断；
  4. 加工要求导向：应限制哪些自由度由工序加工要求决定，而非一律要求完全定位；
  5. 分析方法：除传统的六点定位原理外，还可以借助齐次线性方程组、定位法线几何定理等更严谨的分析工具处理复杂定位问题。
