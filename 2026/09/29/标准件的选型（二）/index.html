标准件的选型（二）

发表于2026-09-29|更新于2026-09-29|选型计算
|浏览量:

电机分类全貌与各类型核心选型计算方法

电机按工作电源可分为直流电机与交流电机两大族系，按控制方式又衍生出伺服电机、步进电机、直线电机等专用类型，每种电机的工作原理与特性参数差异决定了其选型计算的侧重点不同——异步电机重功率与起动转矩校核，伺服电机重惯量匹配与均方根转矩，步进电机重矩频曲线与保持转矩，直流电机重调速特性与反电势常数，直线电机则直接以推力替代扭矩进行计算。

一、电机分类总览

交流同步电机 永磁同步(PMSM)、电励磁、磁阻同步 转子与旋转磁场严格同步 新能源车、精密传动、发电机 功率、功率因数、效率

二、交流异步电机选型计算

异步电机是工业用量最大的电机类型，选型以功率计算为起点，起动转矩与过载能力为校核终点。

1. 负载功率计算

根据负载类型采用不同公式：

  • 通用功率公式：P(kW) = T(N·m) × n(r/min) / 9550，其中 T 为负载扭矩，n 为转速。
  • 风机水泵（平方转矩）：P = Q·H·ρ·g / (3600×1000×η)，Q 为流量(m³/h)，H 为扬程(m)，ρ 为介质密度，η 为泵效率。
  • 传送带（恒转矩）：P = F·v / 1000，F 为牵引力(N)，v 为带速(m/s)。
  • 考虑传动效率：P轴 = P负载 / η传动，η传动 为传动链总效率（联轴器 0.980.99，齿轮减速机 0.900.98，平皮带 0.92~0.95）。

2. 安全系数与功率选定

负载情况 安全系数 K
平稳负载 1.1~1.15
冲击性负载 1.2~1.5
频繁启停(≥10次/小时) 1.3~1.4

3. 起动转矩校核

电机起动转矩 Tst 须满足：Tst ≥ 1.2 × 负载静转矩。

异步电机起动转矩通常为额定转矩的 1.52.5 倍，起动电流为额定电流的 57 倍；若起动转矩不足，需选绕线式异步电机或高起动转矩电机（如 YE4 系列，起动转矩 ≥2.0 倍额定）。

4. 额定电流计算

三相异步电机额定电流：

Ie = P / (√3 × U × η × cosφ)

以 11kW、4极 YE3 电机为例（效率 89.4%，功率因数 0.89）：

Ie = 11 / (1.732×380×0.894×0.89) ≈ 20.8A

5. 过载能力校核

电机最大转矩 Tmax 与额定转矩 Tn 之比（过载倍数）须满足负载短时过载需求。

  • 冲击性负载过载倍数 ≥1.8 倍
  • 恒转矩负载 ≥1.5 倍

示例：某水泵轴功率 15kW，转速 1450rpm，普通车间环境。选型步骤：

  1. P电机 = 15×1.1 = 16.5kW → 选 18.5kW 标准型号；
  2. T = 9550×18.5/1450 = 121.8N·m；
  3. 防护等级 IP54、F级绝缘、能效 IE3。

三、交流伺服电机选型计算

伺服电机本质为永磁同步电机加编码器闭环，选型计算最为复杂，核心是惯量匹配、峰值转矩与均方根转矩三项校核。

1. 负载惯量计算（折算到电机轴）

不同机构折算公式：

  • 滚珠丝杠传动：
    • 工件折算惯量：Jw = M × (Pb / 2π)²，M 为负载质量，Pb 为丝杠导程；
    • 丝杠自身惯量：Jb = Mb × Db² / 8，Mb 为丝杠质量，Db 为丝杠直径；
    • 总负载惯量：JL = Jw + Jb + J联轴器。
  • 同步带传动：JL = M × (D/2)² / R²，D 为带轮直径，R 为减速比。
  • 圆盘负载（回转工作台）：JL = M × D² / 8。

2. 转速计算

  • 丝杠传动：n = v / Pb，v 为最大线速度；
  • 同步带传动：n = v × 60 / (π × D) × R。

要求电机额定转速 > 工作最高转速。

3. 转矩计算

  • 摩擦转矩：Tf = M·g·μ·Pb / (2π·η)（丝杠传动），μ 为摩擦系数，η 为传动效率；
  • 加速转矩：Ta = (JL + JM) × α，α = 2π·n / (60·t1)，t1 为加速时间；
  • 峰值转矩：Tpeak = Ta + Tf，须 < 电机瞬时最大转矩（留 20% 余量）；
  • 均方根转矩：

Trms = √[(Ta²×t1 + Tv²×t2 + Td²×t3) / tcycle]

须 < 电机额定转矩（留 20% 余量），tcycle 为循环周期。

4. 惯量匹配校核

惯量比 K = JL / JM 须满足：

  • 高动态伺服系统：K ≤ 3
  • 通用伺服：K ≤ 5~10

若 K 过大，需加减速机（等效惯量按 1/i² 衰减）。

5. 选型四原则

  1. 连续工作扭矩 < 电机额定扭矩；
  2. 瞬时 MAX 扭矩 < 伺服电机 MAX 扭矩；
  3. 负载惯量 < 3 倍电机转子惯量；
  4. 连续工作速度 < 电机额定转速。

示例：滚珠丝杠传动，负载 M=200kg，导程 Pb=20mm，丝杠 Db=50mm、Mb=40kg，摩擦系数 μ=0.2，效率 η=0.9，速度 v=30m/min，加减速时间 t1=t3=0.2s，匀速 t2=1s，停止 t4=0.3s。

计算结果：

  • Jw = 200×(0.02/6.28)² = 20.29 kg·cm²
  • Jb = 40×25/8 = 125 kg·cm²
  • JL = 145.29 kg·cm²
  • n = 30/0.02 = 1500 rpm
  • Tf = 200×9.8×0.2×0.02/(6.28×0.9) = 1.387 N·m
  • Ta = 12.672 N·m
  • Tpeak = 14.059 N·m
  • Trms = 6.914 N·m

最终选定 SM180 伺服电机。

四、步进电机选型计算

步进电机选型以步距角（分辨率）、保持转矩（静转矩）和矩频特性曲线为三大核心依据。

1. 步距角（分辨率）确定

根据定位精度需求选择：

电机类型 步距角
两相电机 1.8°/步（整步），细分后可达 0.18° 甚至更小
三相电机 1.2°/步
五相电机 0.72°/步（精度高但成本贵）

脉冲当量计算：脉冲当量 = 导程 / (每转脉冲数)。

例如丝杠导程 5mm，4 细分：5/(200×4) = 0.00625mm = 6.25μm。

2. 负载转矩计算

  • 摩擦转矩：Tf = M·g·μ·r / η（皮带传动），r 为带轮半径；
  • 加速转矩：Ta = JL·α = JL·(2π·n)/(60·t1)；
  • 所需转矩：Tneed = (Tf + Ta) × 安全系数。

安全系数取值：

速度 安全系数 SF
低速(<300rpm) 1.5~2.0
高速(>300rpm) 2.5~3.5

3. 保持转矩选定与矩频曲线校核

保持转矩是步进电机选型的首要参数，建议为负载所需静转矩的 1.3~1.5 倍。

但保持转矩不等于高速输出转矩——步进电机输出转矩随脉冲频率上升而下降，必须查矩频特性曲线，确认工作点（转速 nmax，转矩 Tneed）落在连续运行区域之内，且对应转速下的输出转矩 T2 须比 Tneed 大 20% 以上。

4. 惯量匹配校核

步进电机负载惯量比：K = JL / JM ≤ 5~10。

惯量比过大将导致启动失步、停止过冲，建议加大电机座号或加齿轮减速箱。

5. 运行模式确定

  • 矩形曲线：直接以运行频率启动，需大加速转矩；
  • 梯形曲线：低频启动→加速→匀速→减速→停止，加减速时间设为定位时间的 25% 左右。

五、直流电机（有刷/无刷）选型计算

直流电机选型以转矩常数 Kt、反电势常数 Ke、机械时间常数为核心，体现调速性能与响应特性。

1. 基本公式

  • 转矩常数：Kt = T / I（N·m/A），表示单位电流产生转矩；
  • 反电势常数：Ke = E / ω（V·s/rad），与 Kt 在 SI 单位制下数值相等；
  • 转矩-转速方程：T = Kt·I - (Kt²/R)·ω，R 为电枢电阻；
  • 机械特性：n = (U - I·R) / Ke。

2. 选型步骤

  1. 根据负载转矩 T 与目标转速 n，计算所需电枢电流 I = T / Kt；
  2. 核算端电压 U = Ke·ω + I·R 是否在供电范围内；
  3. 校核电机常数 Km = Kt/√R，Km 越大电机性能越优；
  4. 校核连续电流与峰值电流是否满足加减速需求；
  5. 核算散热与温升。

3. 有刷与无刷差异

  • 有刷直流电机：调速简单（调压即可），启动转矩可达额定 2~3 倍，但需维护电刷，适合成本敏感、低压场景；
  • 无刷直流电机(BLDC)：电子换向，效率 >90%，寿命长，需配电子控制器，适合无人机、电动车等高可靠场景。

4. 串励/并励/他励特性

  • 串励直流电机：起动转矩达额定 5 倍以上，转速随负载变化大，空载飞车风险，适合起重、卷扬；
  • 并励直流电机：起动转矩约为额定 2.5 倍，转速变化率 5%~15%，适合风机、泵类；
  • 他励直流电机：调速范围宽，可通过调电枢电压（向下调）和调励磁（向上调）实现宽调速。

六、直线电机选型计算

直线电机将旋转电机“展开”，以推力替代转矩、以质量替代惯量，计算逻辑与伺服电机类似但单位体系不同。

1. 参数定义

  • ML：负载总质量；
  • S：行程；
  • a：加速度；
  • t1/t2/t3：加速/匀速/减速时间；
  • Fa/Fv/Fd：加速段/匀速段/减速段推力(N)；
  • Fp：峰值推力；
  • Fc：连续推力；
  • Frms：有效推力。

2. 推力计算

  • 加速度：a1 = Vmax / t1；
  • 加速段推力：Fa = ML·a1 + Ff，Ff 为摩擦力；
  • 减速段推力：Fd = ML·a3 + Ff；
  • 匀速段推力：Fv = Ff。

3. 选型校核

  • 峰值推力：Fpeak = max{Fa, Fd}，要求 Fp ≥ 1.2 × Fpeak；
  • 有效推力：Frms = √[(Fa²·t1 + Fv²·t2 + Fd²·t3) / t]，要求 Fc ≥ 1.2 × Frms；
  • 推力常数：Kf = Fp / Ip（N/Arms），用于反算驱动器电流。

4. 有铁芯 vs 无铁芯

  • 有铁芯(T形)：推力密度高（2~5kN 连续推力），但存在法向吸力，需高刚性导轨；
  • 无铁芯(U形)：无吸力，惯量低适合高加速，但推力密度较低、成本高。

5. 直线步进电机推力换算

T = F × Pb / (2π·η)，其中 Pb 为丝杠导程，η 为效率。

示例：1N·m 步进电机配 8mm 导程滚珠丝杠（η=0.8）：

F = 1×6.28×0.8/0.008 = 628N，约可推动 30~40kg 负载。

七、永磁同步电机选型要点

永磁同步电机(PMSM)本体既是伺服电机也是新能源车主驱电机，选型核心区别在于控制方式与应用场景。

  • 效率与功率因数：效率 >95%，功率因数接近 1，适合长期连续运行节能改造；
  • 弱磁扩速：永磁电机在基速以下恒转矩运行，基速以上通过弱磁实现恒功率扩速，扩速比可达 3~5 倍；
  • 齿槽转矩：影响低速平稳性，选型时需关注齿槽转矩占比（<1.5% 额定转矩）；
  • 高温退磁风险：钕铁硼磁钢耐温 180℃，超过需选钐钴磁钢型号。

八、统一选型计算流程

不同电机类型虽有差异，但底层逻辑一致，可归纳为六步闭环：

  1. 明确负载类型与运动需求：恒转矩/恒功率/平方转矩，定位精度，加减速频次；
  2. 计算负载转矩：T = F·r（旋转）或 F = ML·a（直线），叠加摩擦、重力分量；
  3. 计算折算惯量：JL = M·(Pb/2π)²（丝杠）或 M·D²/8（圆盘），逐项叠加；
  4. 计算峰值转矩与均方根转矩：Tpeak = Ta + Tf；Trms 按工作循环平方积分；
  5. 校核惯量比与转速：K = JL/JM 落入推荐区间；nmax < 电机额定转速；
  6. 匹配环境防护与安装：IP 防护等级、绝缘等级、防爆等级、安装方式（IM B3/V1 等）。

九、通用方法总结

方法 特点 适用场合
经验类比法 参考同类设备，凭经验或手册估算 简单、非关键、初步估算
计算选型法 根据负载转矩、转速、功率、惯量、工作制计算，再查样本校核 最常用、最可靠，适用于绝大多数设备
查样本/查表法 按功率、转速、安装方式、防护等级直接查厂家样本 常作为计算后的最后一步

最常用的是：计算选型法，尤其是“负载转矩/功率计算 + 样本校核”。

它通常分两步：

  1. 先算负载需求
    普通电机常用功率法：
    [
    P=\frac{T_L n}{9550}
    ]
    或
    [
    P=\frac{Fv}{1000\eta}
    ]
    再考虑安全系数，选标准功率等级。

  2. 再校核
    查电机样本，校核启动转矩、最大转矩、发热、过载能力、转速范围、安装尺寸等。
    如果是伺服或步进电机，还要校核：

    • 连续转矩 (T_{rms})
    • 加速转矩 (T_a=J\alpha)
    • 峰值转矩
    • 惯量比
    • 转矩—转速曲线

补充：惯量比是什么？它主要表示电机的哪些特征？

1. 惯量比的定义

惯量比通常定义为：

K = JL / JM

其中：

  • JL：负载折算到电机轴上的总惯量，包括工件、丝杠、联轴器、减速机、皮带轮等所有运动部件折算到电机轴后的惯量；
  • JM：电机转子自身的惯量，由电机样本给出；
  • 两者单位必须一致，常用 kg·m² 或 kg·cm²。

工程上说的“惯量比”一般指 JL / JM。少数资料可能用 (JL + JM) / JM 或 (JM + JL) / JM，阅读时需先确认定义。

2. 物理意义

惯量是物体抵抗角加速度的能力。电机转子惯量 JM 表示电机自身转子的惯性大小；负载惯量 JL 表示负载折算到电机轴后的惯性大小。

惯量比 K 描述的是：负载惯性相对于电机自身惯性有多大。

忽略摩擦时，电机轴上的角加速度为：

α = T / (JM + JL) = T / [JM × (1 + K)]

因此：

  • K 越小，负载惯量相对电机惯量越小，电机对负载的控制裕度越大；
  • K 越大，负载惯量相对电机惯量越大，电机越像“小马拉大车”，加速、减速和控制都更困难；
  • 要达到同样角加速度，K 越大，所需转矩越大，大致按 (1 + K) 的比例增加。

3. 它主要表示电机的哪些特征？

惯量比不是电机的功率、效率、转矩常数等静态参数，而是 “电机—负载—传动”系统的动态匹配指标。它主要表示以下特征：

（1）电机的动态响应能力

K 小，说明电机转子惯量相对负载足够大，系统控制裕度大，动态响应更容易做快、做稳。

K 大，说明负载惯量占主导，系统机械时间常数增大，响应变慢，跟随误差和整定时间都会增加。

（2）控制稳定性与调参难度

伺服驱动器的位置环、速度环增益与惯量比密切相关。

  • K 小：增益可以设得较高，系统稳定，调试容易；
  • K 大：增益必须降低，否则容易振荡、超调，甚至引发机械共振；
  • K 过大时，靠驱动器参数整定往往压不住，必须从机械传动上降低惯量比。

（3）电机的加速能力与转矩需求

由 α = T / [JM(1+K)] 可知：

  • 同样转矩下，K 越大，加速度越小；
  • 要达到同样加速度，K 越大，所需峰值转矩和均方根转矩越大；
  • 因此惯量比直接影响伺服电机的 Tpeak 和 Trms 校核结果。

（4）电机转子惯量 JM 的相对大小

JM 是电机本体的固有参数：

  • JM 小：电机“轻快”，动态响应潜力大，但可匹配的负载惯量也小，K 容易偏大；
  • JM 大：电机“沉稳”，抗负载扰动能力强，但自身加速慢，体积、成本和转矩需求通常也更高。

所以惯量比也间接反映了：这台电机的转子惯量是否足以“镇住”当前负载的惯性。

（5）惯量匹配水平

惯量比是伺服电机和步进电机选型中的核心动态指标：

  • 高动态伺服系统：K ≤ 3；
  • 通用伺服系统：K ≤ 5~10；
  • 步进电机：K ≤ 5~10。

K 过大时，步进电机容易启动失步、停止过冲；伺服电机容易振荡、超调、发热和报警。

（6）系统级匹配特征，而非电机单独特征

惯量比不是电机单独能决定的，它取决于：

K = 负载折算惯量 / 电机转子惯量

所以它是“电机 + 传动 + 负载”的系统指标。电机本体的 JM 决定分母，机械结构和传动比决定分子。选型时不能只看电机样本上的 JM，必须先把负载惯量折算到电机轴。

4. 惯量比过大时怎么调整？

常用手段：

  1. 加减速机：折算到电机轴的负载惯量按 1/i² 衰减，惯量比变为
    K' = JL / (i² × JM) = K / i²
    这是最有效的降惯量比手段，但会引入背隙、效率损失和成本。
  2. 换大转子惯量的电机：JM 增大，K 减小，但需复核额定转矩、额定转速和成本。
  3. 减轻负载或减小运动部件惯量：如减轻工件质量、减小丝杠直径、优化转台结构。
  4. 改变传动比或传动方式：如用同步带、减速箱替代直驱。

需要注意：惯量比不是越小越好。K 过小可能意味着电机选得过大，成本、体积和自身惯量都浪费，整体加速反而未必最快。合理匹配才是目标。

5. 总结

惯量比 K = JL / JM 不是电机的功率或转矩参数，而是描述 电机转子惯量与负载折算惯量之间匹配程度 的动态指标；它主要表示电机的动态响应能力、加速能力、控制稳定性、转矩需求以及系统好不好控，是伺服和步进电机选型中决定“跟不跟得上、稳不稳得住”的关键特征。
