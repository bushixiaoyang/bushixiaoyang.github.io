机械基础笔记：力、力矩、应力与材料性能

逻辑主线：
载荷 → 内力（力 / 力矩 / 扭矩 / 弯矩）→ 应力 → 材料性能（强度 / 刚度 / 硬度 / 韧性 / 塑性 / 疲劳强度）→ 设计校核

1. 基础量：载荷、力、力矩、应力

1.1 载荷

定义：使零件产生内力、变形或破坏的一切外来因素。
不只是“力”，也可以是力矩、温度、压力、腐蚀、惯性力等。

分类：

类型 特点 例子
静载荷 大小、方向不随时间变化或缓慢变化 自重、缓慢加压
动载荷 随时间变化 旋转件受力、振动
交变载荷 周期性变化 轴、齿轮、弹簧
冲击载荷 瞬间作用 锻锤、冲压、碰撞

单位：

  • 集中力：N
  • 分布力：N/m
  • 面载荷 / 压力：Pa、MPa
  • 力矩：N·m

应用：所有强度、刚度、寿命计算的输入条件。

1.2 力

定义：物体之间的相互作用，使物体运动状态改变或产生变形。
三要素：大小、方向、作用点。

公式：

  • 牛顿第二定律：( F = ma )
  • 重力：( G = mg )

单位：N（牛顿）

分类：

  • 集中力
  • 分布力
  • 体积力（重力、惯性力）

应用：受力分析、自由体图、支座反力计算。

1.3 力矩

定义：力使物体绕某点或某轴转动效应的量度。

公式：
[
M = F \times d
]

  • ( F )：力
  • ( d )：力臂，力到转轴的垂直距离

单位：N·m 或 N·mm
方向：右手定则

应用：扳手拧螺栓、杠杆、平衡计算。

1.4 应力

定义：材料单位面积上承受的内力。

公式：
[
\sigma = \frac{F}{A}
]
[
\tau = \frac{F}{A}
]

  • ( \sigma )：正应力，垂直于截面
  • ( \tau )：切应力，平行于截面
  • ( A )：截面面积

单位：

  • Pa
  • MPa，( 1\ \text{MPa} = 1\ \text{N/mm}^2 )
  • GPa，( 1\ \text{GPa} = 1000\ \text{MPa} )

胡克定律：
[
\sigma = E \varepsilon
]
[
\tau = G \gamma
]

  • ( E )：弹性模量，单位 GPa
  • ( G )：切变模量，单位 GPa
  • ( \varepsilon )：正应变，无量纲
  • ( \gamma )：切应变，无量纲

应用：强度校核核心指标，判断材料是否屈服或断裂。

2. 内力矩：转矩、扭矩、弯矩

2.1 转矩

定义：使机械元件绕轴转动的力矩。

公式：
[
T = 9550 \frac{P}{n}
]

  • ( T )：转矩，N·m
  • ( P )：功率，kW
  • ( n )：转速，r/min

单位：N·m

应用：电机选型、减速器、联轴器、传动系统设计。

2.2 扭矩

定义：轴受扭转时，横截面上由切应力构成的内力偶矩。
侧重“轴内部抵抗扭转的内力”。

公式：
[
\tau_{\max} = \frac{T}{W_p}
]
[
\theta = \frac{T L}{G I_p}
]

  • ( T )：扭矩，N·m
  • ( W_p )：抗扭截面系数，mm³
  • ( I_p )：极惯性矩，mm⁴
  • ( \theta )：扭转角，rad
  • ( L )：轴长，mm

实心圆轴：
[
W_p = \frac{\pi d^3}{16} \approx 0.2d^3
]
[
I_p = \frac{\pi d^4}{32} \approx 0.1d^4
]

应用：传动轴、电机轴、丝杠、联轴器强度与刚度校核。

2.3 弯矩

定义：梁或轴受弯曲时，横截面上由正应力构成的力矩。

公式：
[
\sigma = \frac{M y}{I_z}
]
[
\sigma_{\max} = \frac{M}{W_z}
]
[
\frac{dM}{dx} = V
]

  • ( M )：弯矩，N·m 或 N·mm
  • ( y )：到中性轴距离
  • ( I_z )：截面惯性矩，mm⁴
  • ( W_z )：抗弯截面系数，mm³
  • ( V )：剪力

常见截面：

  • 矩形：( W_z = \frac{bh^2}{6} )，( I_z = \frac{bh^3}{12} )
  • 圆截面：( W_z = \frac{\pi d^3}{32} \approx 0.1d^3 )

应用：梁、轴、机架、支架的弯曲强度与刚度校核。

2.4 力矩、转矩、扭矩、弯矩对比

概念 侧重点 公式 单位 典型应用
力矩 力使物体转动 ( M=Fd ) N·m 扳手、杠杆
转矩 使机械元件转动 ( T=9550P/n ) N·m 电机、减速器
扭矩 轴内部抵抗扭转 ( \tau_{\max}=T/W_p ) N·m 传动轴
弯矩 梁截面抵抗弯曲 ( \sigma_{\max}=M/W_z ) N·m 梁、轴

3. 材料核心性能

3.1 强度

定义：材料抵抗塑性变形和断裂的能力。

主要指标：

指标 含义 符号 单位
弹性极限 不产生塑性变形的最大应力 ( \sigma_e ) MPa
屈服强度 开始明显塑性变形的应力 ( \sigma_s / R_{eL} ) MPa
条件屈服强度 残余变形 0.2% 时应力 ( R_{p0.2} ) MPa
抗拉强度 拉断前最大应力 ( \sigma_b / R_m ) MPa

设计原则：

  • 塑性材料：以屈服强度为主要依据
  • 脆性材料：以抗拉强度为主要依据
  • 许用应力：
    [
    [\sigma] = \frac{\sigma_{\lim}}{n}
    ]
  • ( \sigma_{\lim} )：极限应力
  • ( n )：安全系数，( n>1 )

应用：螺栓、轴、压力容器、结构件选材与校核。

3.2 刚度

定义：材料或结构抵抗弹性变形的能力。

公式：
[
k = \frac{F}{\delta}
]

  • ( k )：刚度，N/m
  • ( F )：力，N
  • ( \delta )：变形量，m 或 mm

材料层面：

  • 弹性模量 ( E )
  • 切变模量 ( G )
  • 单位：GPa

结构层面：

  • 弯曲刚度：( EI )
  • 扭转刚度：( GI_p )

与强度区别：

  • 强度：会不会坏
  • 刚度：变形大不大

应用：机床主轴、精密导轨、桥梁、弹簧。

3.3 硬度

定义：材料表面抵抗局部塑性变形或划痕的能力。

常用硬度：

类型 符号 压头 适用
布氏硬度 HBW 硬质合金球 退火钢、铸铁
洛氏硬度 HRC 金刚石圆锥 淬火钢、刀具
维氏硬度 HV 金刚石四棱锥 广泛，薄件、表面层

单位：

  • HBW、HV 常写符号，严格单位与 kgf/mm² 相关
  • HRC 无量纲

注意：不同硬度体系不能精确直接换算，只能近似参考。

应用：齿轮齿面、刀具、模具、滚动轴承、耐磨件。

3.4 韧性

定义：材料在断裂前吸收能量的能力。

分类：

  • 冲击韧性：抵抗冲击载荷
  • 断裂韧性：抵抗裂纹扩展

指标：

  • 冲击吸收能量：( KV_2 )，单位 J
  • 冲击韧性：( a_k )，单位 J/cm² 或 kJ/m²
  • 断裂韧性：( K_{IC} )，单位 MPa·m(^{1/2}) 或 MPa√m

应用：

  • 低温结构
  • 船舶、桥梁
  • 承受冲击的零件
  • 含裂纹安全性评估

3.5 塑性

定义：材料产生塑性变形而不破坏的能力。

指标：
[
\delta = \frac{L_u - L_0}{L_0} \times 100%
]
[
\psi = \frac{A_0 - A_1}{A_0} \times 100%
]

  • ( \delta )：断后伸长率
  • ( \psi )：断面收缩率
  • 单位：%

分类：

  • ( \delta \ge 5% )：塑性材料
  • ( \delta < 5% )：脆性材料

应用：

  • 冲压、锻造
  • 过载预警
  • 承受冲击的零件优先选塑性好的材料

3.6 疲劳强度

定义：材料在交变应力作用下，不发生断裂的最大应力。

核心概念：

  • S-N 曲线：应力与寿命关系
  • 疲劳极限：( \sigma_{-1} )，对称循环下
  • 应力比：
    [
    R = \frac{\sigma_{\min}}{\sigma_{\max}}
    ]
  • 平均应力：
    [
    \sigma_m = \frac{\sigma_{\max} + \sigma_{\min}}{2}
    ]
  • 应力幅：
    [
    \sigma_a = \frac{\sigma_{\max} - \sigma_{\min}}{2}
    ]

单位：MPa

特点：

  • 应力可能远低于屈服强度
  • 突然断裂，无明显塑性变形
  • 多数机械失效与疲劳有关

提高措施：

  • 加大圆角，减小应力集中
  • 表面强化：喷丸、渗碳、氮化
  • 降低表面粗糙度
  • 避免尖锐缺口

应用：轴、齿轮、弹簧、连杆、叶片。

4. 易混点

对比 区别
强度 vs 刚度 强度看是否破坏，刚度看变形大小
韧性 vs 塑性 韧性看吸收能量，塑性看残余变形能力
转矩 vs 扭矩 转矩强调使轴转动，扭矩强调轴内部内力偶矩
力矩 vs 弯矩 力矩是广义转动效应，弯矩是弯曲内力矩
应力 vs 载荷 载荷是外力，应力是单位面积内力
硬度 vs 强度 硬度是表面局部抵抗变形，强度是整体抵抗变形和断裂

8. 补充概念

8.1 应变

[
\varepsilon = \frac{\Delta L}{L_0}
]

  • 单位：无量纲，常用 % 或 με
  • 切应变：( \gamma )

8.2 弹性模量、切变模量、泊松比

  • 弹性模量 ( E )：材料抵抗弹性正变形能力，钢约 200 GPa
  • 切变模量 ( G )：材料抵抗弹性切变形能力，钢约 80 GPa
  • 泊松比 ( \nu )：横向应变与纵向应变之比，钢约 0.3
  • 各向同性材料：
    [
    G = \frac{E}{2(1+\nu)}
    ]

8.3 安全系数与许用应力

[
[\sigma] = \frac{\sigma_{\lim}}{n}
]

  • 塑性材料：( \sigma_{\lim} = \sigma_s )
  • 脆性材料：( \sigma_{\lim} = \sigma_b )
  • 疲劳设计：( \sigma_{\lim} = \sigma_{-1} ) 或修正疲劳极限

8.4 应力集中

[
K_t = \frac{\sigma_{\max}}{\sigma_{\text{nom}}}
]

  • 孔、槽、圆角、缺口处应力升高
  • 疲劳裂纹常从应力集中处萌生
  • 设计时应加大圆角、避免尖锐过渡

8.5 截面特性

名称 符号 单位 用途
截面惯性矩 ( I_z ) mm⁴ 弯曲刚度
极惯性矩 ( I_p ) mm⁴ 扭转刚度
抗弯截面系数 ( W_z ) mm³ 弯曲强度
抗扭截面系数 ( W_p ) mm³ 扭转强度

9. 总结

载荷产生内力，内力表现为应力，应力是否危险取决于材料性能；强度防破坏，刚度防变形，硬度防磨损，韧性防冲击，塑性防脆断，疲劳强度防循环载荷下的突然失效。
