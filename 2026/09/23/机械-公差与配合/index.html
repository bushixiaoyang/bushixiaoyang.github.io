机械制图 - 公差与配合

一、互换性与标准化

互换性是指在同一规格的一批零部件中，可以不经选择、调整或修配，任取一件装配在机器上，并能达到规定的使用性能要求。按互换性原则组织生产，可合理进行生产分工和专业化协作，便于采用高效专用设备，缩短生产周期、降低成本，便于装配自动化。

公差与配合的国家标准体系主要包括：GB/T 1800.1—2020《产品几何技术规范（GPS） 线性尺寸公差ISO代号体系 第1部分：公差、偏差和配合的基础》、GB/T 1800.2—2020《第2部分：标准公差等级和孔、轴极限偏差表》、GB/T 1801—2009《极限与配合 公差带和配合的选择》、GB/T 1803—2003《极限与配合 尺寸至18mm孔、轴公差带》、GB/T 1804—2000《一般公差 未注公差的线性和角度尺寸的公差》等。

二、基本术语及定义

（一）孔与轴

  • 孔：通常指工件的圆柱形内表面，也包括非圆柱形内表面（由两平行平面或切面形成的包容面），孔径用大写字母D表示。
  • 轴：通常指工件的圆柱形外表面，也包括非圆柱形外表面（由两平行平面或切面形成的被包容面），用小写字母d表示。
  • 从装配关系讲，孔为包容面，在它之内无材料；轴为被包容面，在它之外无材料。

（二）尺寸相关术语

  • 公称尺寸（旧称基本尺寸）：通过它应用上、下极限偏差可算出极限尺寸的尺寸，通常由设计者给定，用D和d表示。
  • 实际尺寸：通过测量获得的某一孔、轴的尺寸。
  • 极限尺寸：一个孔或轴允许的尺寸的两个极端，实际尺寸应位于其中，也可达到极限尺寸。较大的称为上极限尺寸（Dmax、dmax），较小的称为下极限尺寸（Dmin、dmin）。

（三）偏差与公差

  • 偏差：某一尺寸（实际尺寸、极限尺寸等）减其公称尺寸所得的代数差，其值可正、可负或零。
    • 上极限偏差（孔ES、轴es）= 上极限尺寸 − 公称尺寸
    • 下极限偏差（孔EI、轴ei）= 下极限尺寸 − 公称尺寸
  • 尺寸公差（公差） ：最大极限尺寸减最小极限尺寸之差，或上偏差减下偏差之差，是允许尺寸的变动量，是一个没有符号的绝对值。

（四）间隙与过盈

  • 间隙：孔的尺寸减去相配合的轴的尺寸之差为正。
  • 过盈：孔的尺寸减去相配合的轴的尺寸之差为负。

（五）零线

在极限与配合图解中，表示公称尺寸的一条直线，以其为基准确定偏差和公差。通常零线沿水平方向绘制，正偏差位于其上，负偏差位于其下。

三、标准公差与基本偏差

（一）标准公差等级

标准公差等级代号用符号IT和数字表示，如IT7。标准公差等级分IT01、IT0、IT1至IT18共20级。从IT01至IT18级，公差等级依次降低，相应的标准公差数值则依次增大。对尺寸≤500mm的更高等级（如IT01、IT0和IT1等级），主要考虑测量误差，公差计算采用线性关系式。标准公差数值由公差等级系数和标准公差因子的乘积确定。

（二）基本偏差

基本偏差是指在极限与配合制中，确定公差带相对于零线位置的那个极限偏差。它可以是上偏差或下偏差，一般为靠近零线的那个偏差。

基本偏差代号，对孔用大写字母A、…、ZC表示，对轴用小写字母a、…、zc表示，各28个。其中，基本偏差H代表基准孔；h代表基准轴。

在孔的基本偏差中：A～H为下偏差EI，其绝对值依次减小；J～ZC为上偏差ES（除J和K外）。对轴的基本偏差：a～h为上偏差es；j～zc为下偏差ei（除j和k外）。JS（js）的上、下极限偏差是对称的，上极限偏差值为+IT/2，下极限偏差值为−IT/2。除J（j）以外，A～ZC（a～zc）标准公差等级齐全，分别能与20个公差等级组成公差带。

（三）公差带

公差带在公差带图解中，由代表上偏差和下偏差或最大极限尺寸和最小极限尺寸的两条直线所限定的一个区域。它由公差大小和其相对零线的位置（如基本偏差）来确定。公差带用基本偏差的字母和公差等级数字表示，如孔公差带H7，轴公差带h7。

孔、轴尺寸公差代号由基本偏差代号与公差等级代号组成，如H7、h7。基准孔的基本偏差是下偏差，且等于零，即EI=0，以基本偏差代号H表示，应优先选用。

四、配合

（一）配合的定义与分类

基本尺寸相同的、相互结合的孔和轴公差带之间的关系称配合。配合分为三类：

  • 间隙配合：具有间隙（包括最小间隙为零）的配合。最小间隙≥0。
  • 过盈配合：具有过盈（包括最小过盈为零）的配合。最大间隙≤0。
  • 过渡配合：可能具有间隙或过盈的配合。

（二）配合公差

组成配合的孔、轴公差之和称配合公差，它是允许间隙或过盈的变动量，是一个没有符号的绝对值。

  • 间隙配合的配合公差 Tf = |Xmax − Xmin|
  • 过盈配合的配合公差 Tf = |Ymax − Ymin|
  • 过渡配合的配合公差 Tf = Xmax + Ymax（即最大极限间隙和最大极限过盈之和）

（三）基准制

3.1 什么是基准制

要获得各种不同性质的配合，如果孔和轴的公差带位置都可以自由变动，组合数量将极其庞大，不便于标准化生产。国家标准规定了两种基准制，即固定其中一个零件的公差带位置，通过改变另一个零件的公差带位置来获得各种配合。

3.2 基孔制

定义：基本偏差为一定的孔的公差带，与不同基本偏差的轴的公差带形成各种配合的一种制度。

基孔制中的孔称为基准孔，其基本偏差代号为 H ，下偏差EI = 0。即基准孔的最小极限尺寸等于基本尺寸，孔的公差带位于零线上方（或下偏差为零线）。

在基孔制中，基准孔H与不同基本偏差的轴配合时：

  • 轴的基本偏差为 a～h 时，形成间隙配合
  • 轴的基本偏差为 j～n 时，主要用于过渡配合
  • 轴的基本偏差为 p～zc 时，主要用于过盈配合

3.3 基轴制

定义：基本偏差为一定的轴的公差带，与不同基本偏差的孔的公差带形成各种配合的一种制度。

基轴制中的轴称为基准轴，其基本偏差代号为 h ，上偏差es = 0。即基准轴的最大极限尺寸等于基本尺寸，轴的公差带位于零线下方（或上偏差为零线）。

在基轴制中，基准轴h与不同基本偏差的孔配合时：

  • 孔的基本偏差为 A～H 时，形成间隙配合
  • 孔的基本偏差为 J～N 时，主要用于过渡配合
  • 孔的基本偏差为 P～ZC 时，主要用于过盈配合

3.4 基孔制与基轴制的核心区别

3.5 为什么优先选用基孔制

在常用尺寸范围（500mm以下），一般应优先选用基孔制。原因在于：孔的加工通常需要使用定尺寸刀具（如钻头、铰刀、拉刀）和定尺寸量具（如塞规），如果孔的公差带位置不固定，就需要大量不同规格的刀具和量具，增加生产成本。而轴的加工通常用车削、磨削等方式，不受定尺寸刀具限制，改变轴的公差带位置相对容易且经济。因此，固定孔的公差带、通过改变轴的公差带来获得不同配合，是成本更低的选择。

3.6 何时选用基轴制

在以下情况中，选用基轴制更为合理。

第一，直接使用冷拉圆钢做轴时。 冷拉圆钢的外径已经按一定公差等级制造，不需要再进行切削加工。此时如果还要按基孔制去改变轴的尺寸，反而增加了加工工序，不如以这根现成的轴为基准来加工孔。

第二，同一基本尺寸的轴上有多个不同配合要求的零件时。 例如活塞销与活塞销孔、连杆小头孔的配合，如果采用基孔制，活塞销需要做成阶梯轴，给加工和装配都带来困难，还会降低强度。采用基轴制则可以使活塞销保持同一尺寸，仅改变各孔的公差带。

第三，与标准件配合时，基准制依标准件而定。 这是最典型的情况。滚动轴承是标准件，其内圈与轴的配合采用基孔制（因为内圈内孔是基准孔），外圈与轴承座孔的配合采用基轴制（因为外圈外径是基准轴）。同理，键与键槽的配合采用基轴制，圆柱销与销孔的配合也采用基轴制。

3.7 公差与配合在图样上的标注

在装配图上，配合代号用分数的形式标注，分子为孔的公差带代号，分母为轴的公差带代号。例如：φ30 H7/f6 表示基本尺寸30mm的基孔制间隙配合（孔H7，轴f6）。判断规则：分子中含H的为基孔制，分母中含h的为基轴制。

在零件图上，孔或轴的公差标注有三种形式：

  1. 只注公差带代号：φ30H7（孔）、φ30f6（轴）
  2. 只注极限偏差数值：φ30⁺⁰·⁰²¹₀（孔）
  3. 两者同时标注：φ30H7（⁺⁰·⁰²¹₀）

（四）配合公差带图

配合公差带图用来直观地表达配合性质，即反映配合松紧及其变动情况。在配合公差带图中，横坐标为零线，表示间隙或过盈为零；零线上方的纵坐标为正值（间隙），零线下方的纵坐标为负值（过盈）。

（五）极限间隙与极限过盈的计算

对于基孔制配合，孔的下偏差EI=0，上偏差ES=+IT_孔。轴的基本偏差示例：es_g=−2.5·D^0.34，es_f=−5.5·D^0.41，ei_n=+5·D^0.34（ISO 286）。

最大间隙 = ES_孔 − ei_轴，最小间隙 = EI_孔 − es_轴。

五、几何公差（形位公差）

（一）基本概念

形位公差是工程领域对几何公差的传统称谓之一。根据2018年发布、2019年4月1日实施的现行国家标准GB/T 1182—2018《产品几何技术规范(GPS) 几何公差 形状、方向、位置和跳动公差标注》，该技术指标通常称为“几何公差”。它是对零件几何要素（点、线、面及其组合要素）的形状、方向、位置与跳动等几何特性允许变动范围的规定。

（二）公差项目分类

根据GB/T 1182—2018，几何公差项目通常分为形状公差、方向公差、位置公差和跳动公差四类，共包含14个几何特征符号。

  • 形状公差：单一实际要素的形状对其理想要素所允许的变动量，包括直线度、平面度、圆度、圆柱度、线轮廓度、面轮廓度。
  • 方向公差：关联实际被测要素对具有确定方向的理想要素的允许变动量，包括平行度、垂直度、倾斜度。
  • 位置公差：关联实际被测要素对具有确定位置的理想被测要素的允许变动量，包括同轴度、对称度、位置度。
  • 跳动公差：关联实际被测要素绕基准轴线作无轴向运行时回转一周或连续回转时沿给定方向所允许的最大示值跳动量，包括圆跳动、全跳动。

（三）公差框格标注

几何公差通过公差框格标注，并通过引线、尺寸线等与被测要素建立对应关系。公差框格一般从左至右依次给出：几何特征符号、公差值（必要时在公差值前加注直径符号等）。形状公差通常不需要基准，公差框格仅两格；方向公差、位置公差和跳动公差需要标注基准。

（四）基准与公差带

  • 基准：确定被测要素方向或位置的依据，可由一个或多个基准要素建立，并可按需要构成基准体系。
  • 公差带：用于限定实际要素允许变动范围的区域（如两平行平面之间、圆柱体内等）。

（五）公差原则

公差原则是对尺寸公差与形位公差相互可否转化的规定。尺寸公差与形位公差彼此不允许转化时，为独立原则；允许转化时，为相关原则。相关原则具体可分为包容要求、最大实体要求、最小实体要求及可逆要求，具体标准见GB/T 4249和GB/T 16671。

  • 独立原则：图样上给定的每一个尺寸和几何要求均是独立的，应分别满足要求。
  • 包容要求：提取组成要素不得超越其最大实体边界的一种尺寸要素原则，其局部尺寸不得超出最小实体尺寸。包容要求适用于圆柱表面或两平行对应面。

（六）几何公差项目之间的关系

对某一被测要素给出位置公差后，仅在其方向精度或（和）形状精度有进一步要求时，才另行给出方向公差或（和）形状公差，而方向公差值必须小于位置公差值，形状公差值必须小于方向公差值。

六、表面粗糙度

（一）概念与评定参数

1.1 什么是表面粗糙度

零件表面无论加工得多么精细，在显微镜下观察，总会存在高低不平的微小峰谷。加工表面上具有较小间距和微小峰谷所组成的微观几何形状特性，称为表面粗糙度。它与表面波纹度、形状误差一起构成表面结构的完整描述。

表面粗糙度对零件的配合性质、耐磨性、疲劳强度、密封性和耐腐蚀性都有重要影响，是零件图样上必须标注的重要技术要求。

1.2 主要评定参数

根据国家标准 GB/T 3505—2009 和 GB/T 1031—2009，表面粗糙度的高度特征参数主要有两个：

轮廓算术平均偏差Ra：在取样长度内，轮廓偏距绝对值的算术平均值。Ra是实际测量中最常用的参数，测量点越多，Ra越准确。

轮廓最大高度Rz：在取样长度内，轮廓峰顶线和轮廓谷底线之间的距离。

⚠️ 重要提示：2006年以前的国家标准中，Rz表示“微观不平度十点高度”，轮廓最大高度用Ry表示。GB/T 3505—2000（及后续版本）调整了定义：取消了“微观不平度十点高度”，不再使用Ry，新的Rz为原Ry的定义，即表示轮廓最大高度。阅读旧图纸时需特别注意这一差异。

在常用范围内优先选用Ra作为评定参数。当表面粗糙度很大或很小时，用光学仪器测量Rz更为方便。

此外还有间距特征参数Rsm（轮廓单元的平均宽度）和形状特征参数Rmr(c)（轮廓支承长度率），用于有特殊功能要求的表面。

1.3 表面粗糙度符号与标注

表面粗糙度用代号标注在图样上。代号由符号、数字及说明文字组成。

基本符号：由两条不等长的线段组成，与水平线约成60°角。

去除材料符号：在基本符号上加一条横线，表示该表面需要通过机械加工去除材料获得。

不去除材料符号：在基本符号上加一个圆圈，表示该表面保持铸、锻、轧制等原始状态。

Ra值的标注：由于Ra是最常用的高度参数，标注时数值前不必书写“Ra”代号，直接写数值即可（单位μm）。例如标注“3.2”即表示Ra = 3.2μm。

标注位置：表面粗糙度代号一般注在可见轮廓线、尺寸界线、引出线或其延长线上，符号尖端必须从材料外指向被标注表面。当零件所有表面具有相同的粗糙度要求时，可在图样右上角统一标注。

3.2μm Ra是标准的商用机器加工表面粗糙度，适用于大多数消费零件；1.6μm Ra适用于有配合精度要求的表面；0.8μm Ra适用于精密配合表面。一般冷拔管Ra约为3.2μm，冷轧管Ra约为1.6μm。

1.5 表面粗糙度与公差等级的对应关系

表面粗糙度与尺寸公差等级之间存在经验对应关系：公差等级越高（IT值越小），对应的表面粗糙度Ra值也越小。例如，IT6～IT7级的配合面通常要求Ra ≤ 1.6μm，IT8～IT9级对应Ra ≤ 3.2μm，IT11级以下一般对应Ra ≤ 6.3μm或更大。设计时两者应协调确定，不宜出现“高公差等级却要求很粗糙的表面”这类矛盾。

（二）表面粗糙度与公差等级的对应关系

在通常情况下，机械零件尺寸公差要求越小，其表面粗糙度值也越小，但它们之间不存在固定的函数关系。在一般情况下，有尺寸公差要求的零件，其公差等级与表面粗糙度数值之间有一定的对应关系。

常用对应关系（举例）：

公差等级 基本尺寸≤50mm（轴/孔）Ra 基本尺寸>50～500mm（轴/孔）Ra
IT5 0.2 / 0.4 0.4 / 0.8
IT6 0.4 / 0.4～0.8 0.8 / 0.8～1.6
IT7 0.4～0.8 / 0.8 0.8～1.6 / 1.6
IT8 0.8 / 0.8～1.6 1.6 / 1.6～3.2

配合性质相同，零件尺寸越小，其表面粗糙度值越小；同一精度等级，轴比孔的Ra值要低。

（三）表面粗糙度与形状公差的关系

在特定加工条件下，表面粗糙度与形状公差之间存在比例关系，通常表面粗糙度Ra值可认为是形状公差值的20%～25%。

七、尺寸公差与配合的标注

标注方法依据GB/T 4458.5—2003《机械制图 尺寸公差与配合注法》，该标准规定了机械图样中尺寸公差与配合公差的标注方法。

（一）零件图上的公差注法

线性尺寸的公差应按下列三种形式之一标注：

  1. 公差带代号标注：公差带代号注在基本尺寸的右边，如Φ50H7、Φ50h6。
  2. 极限偏差标注：上偏差注在基本尺寸的右上方，下偏差与基本尺寸注在同一底线上，上下偏差的数字字号比基本尺寸小一号。
  3. 同时标注：同时标注公差带代号和相应的极限偏差时，后者应加圆括号。

（二）装配图上的配合注法

在装配图上标注配合代号时，必须在基本尺寸的右边用分数的形式注出，分子为孔的公差带代号，分母为轴的公差带代号，如Φ50H7/g6。

（三）注公差尺寸的表示

注公差的尺寸用公称尺寸后跟所要求的公差带或（和）对应的偏差值表示，如32H7、80js15、100g6。配合用相同的基本尺寸后跟孔、轴公差带表示，孔、轴公差带写成分数形式，分子为孔公差带，分母为轴公差带，如52H7/g6。

八、检验与测量

（一）光滑极限量规

光滑极限量规适用于孔与轴基本尺寸至500mm、公差等级IT6级至IT16级的光滑极限量规。泰勒原则是设计极限量规的依据，用这种极限量规检验零件，基本可以保证零件公差与配合要求。量规设计采用内缩原则：量规的尺寸公差带全部位于被检验零件的尺寸公差带以内。

光滑塞规是一种用于检验工件内尺寸的精密量具，其测量标准条件为温度20℃且测力为零，不能测出被检尺寸的具体数值，只能判断被检尺寸是否合格。产品分为通端和止端，通端对应工件最小极限尺寸，止端对应工件最大极限尺寸。

（二）常用计量器具

  • 游标卡尺：适用于高度、长度、厚度、深度、外径和内径等简单几何体的尺寸测量。
  • 外径千分尺：用于测量轴类零件的外径尺寸，测量精度比游标卡尺更高。
  • 内径百分表：常用于测量深孔和公差精度较高的孔，主要由表、手柄主体、定位护桥、活动测头、可换测头、紧固螺钉等几部分组成，可测量10～450mm的内径，读数值有0.01、0.005、0.001三种，实际使用时常选用0.01。

（三）测量操作要点

根据被测尺寸的大小和精度要求选用量具：一要考虑测量尺寸的大小，二要考虑测量精度。检验时需判断实测尺寸是否位于极限尺寸范围之内，以确定零件是否合格。

九、未注公差（一般公差）

GB/T 1804—2000《一般公差 未注公差的线性和角度尺寸的公差》规定了未注出公差的线性和角度尺寸的一般公差等级和极限偏差数值，适用于金属切削加工的尺寸，也适用于一般的冲压加工的尺寸。该标准等效采用国际标准ISO 2768—1:1989。未注公差按m级标准（中等精度）执行。

（二）基轴制优先配合

基轴制配合中，轴的基本偏差代号为h（基准轴），孔的基本偏差代号为A～H等不同字母，与基孔制形成对称关系。

十一、公差等级与加工方法的关系

常用加工方法所能达到的公差等级参考：IT5～IT6级对应精磨、研磨；IT7～IT8级对应精车、精铣；IT9～IT10级对应普通车削、铣削；IT11～IT12级对应粗车、钻孔；IT13～IT18级对应锻造、铸造等。表面粗糙度与公差等级的对应关系已在第六节中说明。
